## 文件分區

- `architecture/`：系統架構、模組邊界、技術債與重構方向
- `architecture/`：系統架構、模組邊界、技術債、資料品質治理
- `核心資料/正式preset/`：正式角色 prompt 範本，與工程規格分開維護
- `project/`：專案定位、主要檔案與現況說明
- `process/`：開發規則、發佈流程、維護準則、資料新增規格
- `development-log/`：版本與工程整理紀錄
