# 資料新增規格

## 目標

避免新增卡片時只寫場景，導致生成動作單調、構圖呆板、臉身不協調。

## 最低必填

每張新卡片至少應有：

- `id`
- `name`
- `sub`
- `scene`
- `outfit`
- `prop`

## 建議完整欄位

- `scene`
- `outfit`
- `prop`
- `comp`
- `fx`
- `mk`
- 視需要補 `ratio` / `lens` / `ang` / `camLang`

## `prop` 撰寫原則

應該描述：

- 主體正在做什麼
- 手部如何放
- 是否坐著、走動、回眸、持物
- 如何與場景互動

避免：

- 抽象空話
- 只有情緒沒有動作
- 過度高難度動作
- 遮住臉或讓臉身難以對齊的姿勢

## `comp` 撰寫原則

應該描述：

- 是全身、半身、環境式還是近景
- 主體相對鏡頭的角度
- 臉如何保持清楚
- 道具 / 背景如何進畫面

## 特別規則

由於使用者常用正面人像作為原始參考照：

- 姿勢優先正面友善
- 優先三分之三面、正面、輕回眸
- 避免極端扭身、全背面、高難度舞蹈式姿勢
