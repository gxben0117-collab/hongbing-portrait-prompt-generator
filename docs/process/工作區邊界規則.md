# 工作區邊界規則

## 單一事實來源

正式開發來源只有：

- `index.html`
- `core.js`
- `scripts/`
- `docs/`
- `核心資料/`

## 非來源目錄

以下目錄不是主要開發來源：

- `dist/`
- 外部 `output/` 分發資料夾
- `.venv/`
- `__pycache__/`

## 規則

### `dist/`

- 定位：建置產物
- 不應反向成為主要修改來源

### 外部分發資料夾

- 定位：交付 / 測試 / 分發副本
- 不應先在那裡修改，再回頭猜主工程

### `.venv/`

- 定位：本機環境
- 不屬於產品邏輯本身

## 維護結論

未來若主工程、`dist/`、外部分發資料夾內容不一致：

以主工程為準，再重新建置與同步。
