# 工程維護規則

## 紅線

`核心資料/核心咒語規範.md` 未獲使用者明確同意不得修改。

## 維護原則

1. 優先可維護性
2. 優先清晰結構
3. 保留相容性
4. 不危險刪檔
5. 先整理邊界，再做大重構

## 工程操作規則

### 修改核心邏輯時

- 可調整 `core.js` 的非核心規範層行為
- 但不得私自改動核心規範文本來源

### 修改資料時

- 盡量補齊 `prop` / `comp` 等資料完整性
- 避免只加 `scene` 導致模型回到靜態站姿

### 發佈時

- 以 `dist/` 為正式產物目標
- 使用腳本同步 `index.html` / `core.js`

## 建議日常指令

- `npm run check:structure`
- `npm run build:dist`
- `npm run report:data-gaps`
