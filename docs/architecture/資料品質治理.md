# 資料品質治理

## 現況結論

資料品質掃描顯示，大量分類存在以下情況：

- 只有 `scene`
- 沒有 `prop`
- 沒有 `comp`

這會直接導致：

1. 模型回到預設站姿
2. 動作與視角不夠穩定
3. 同分類內畫面語言重複
4. 後期新增卡片品質依賴運氣而不是結構

## 已確認的高風險分類

特別需要優先治理的分類：

- `hanfu`
- `fantasy`
- `gothic`
- `water`
- `wedding_diamond`
- `cyberpunk_sf`
- `game`
- 各旅拍類分類

## 治理原則

### 1. 不追求一次補完整庫

先做分層治理：

- 第一層：核心 prompt 自動補安全姿勢邏輯
- 第二層：分類專屬姿勢庫
- 第三層：對高價值分類補 `prop`
- 第四層：再補 `comp`

目前狀態：

- 第一層：已完成
- 第二層：已完成第一版，已涵蓋旅拍、婚紗、漢服 / 朝代、女王 / 魔王等大類
- 第三層與第四層：仍需分批把資料本體補齊

### 2. `prop` 的角色

`prop` 不是單純道具欄位，而是：

- 動作描述
- 手部位置
- 與場景互動方式
- 是否站立 / 坐姿 / 緩步 / 回眸 / 持物

### 3. `comp` 的角色

`comp` 決定：

- 全身 / 半身 / 三分之二身
- 正面 / 三分之三面
- 低角度 / 環境式 / 封面式
- 如何讓畫面穩定又不呆

## 建議補強順序

1. 旅拍分類
2. 婚紗分類
3. 漢服 / 朝代 / 神話古典分類
4. 女王 / 魔王 / 墮天使這類高敘事分類
5. 科幻 / 動漫 / COS

## 資料新增最低標準

未來新增卡片，至少要有：

- `scene`
- `outfit`
- `prop`

理想完整格式：

- `scene`
- `outfit`
- `prop`
- `comp`
- `fx`
- `mk`
