# 版本規則

## 文件版本格式

使用 `V` 加兩位小數：

```text
V1.00
V1.01
V1.02
```

## 網頁版本格式

主頁沿用現有 HTML 版本格式：

```text
v0.10
v0.11
v0.12
v0.13
v0.14
v0.15
v0.16
v0.17
v0.18
v0.19
v0.20
v0.21
v0.22
v0.23
v0.24
v0.25
```

## 累積方式

- 文件更新版本：每次文件有實際更新時，版本號加 `0.01`
- 網頁主程式版本：每次實際功能更新時，沿用 `v0.xx` 累積

## 保留規則

- 舊版 HTML 不可刪除。
- 舊版 HTML 統一保留在 `versions/`。
- 目前主版本固定為根目錄 `index.html`。
- 核心資料統一保留在 `核心資料/`。
- 每次更新都建立新的 `development-log/Vx.xx.md`。
- 如果有改動專案定位、命名或流程，也要同步更新文件。
- 若只是查看或討論，沒有實際更動檔案，可以不新增版本。
