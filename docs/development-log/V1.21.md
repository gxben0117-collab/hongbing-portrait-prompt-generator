# V1.21

日期：2026-05-22

## 本次更新

1. 在 `core.js` 新增 `CORE_FACE_BODY_COHERENCE` 執行層規則。
2. 明確定義：
   - 臉部身份穩定性高於姿勢戲劇性
   - 頭部角度、脖子、肩線、軀幹扭轉必須與來源臉部視角自然相容
   - 若姿勢會造成頭臉像貼在錯誤身體上，必須立即降階成更安全動作
3. 在 `buildPoseGuidance(...)` 補上 `Face-body priority rule`，讓行為選擇除了角色邏輯，也必須服從頭臉與身體的一致性。

## 階段結論

目前系統除了鎖五官與角色行為導向外，已新增一層更強的「臉身一致性優先」保護，專門壓制臉部穩定但身體姿勢不協調的情況。
