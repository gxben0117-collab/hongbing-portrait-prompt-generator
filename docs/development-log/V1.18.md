# V1.18

日期：2026-05-22

## 本次更新

1. 在 `core.js` 正式建立分類專屬姿勢庫第一版。
2. 目前已覆蓋的大類：
   - 旅拍
   - 婚紗
   - 漢服 / 朝代 / 古典延伸類
   - 女王 / 魔王 / 高權威敘事類
3. 專屬姿勢庫採低風險相容策略：
   - 若卡片本身已有 `prop` / `comp`，尊重原始資料
   - 若卡片缺 `prop` / `comp`，由分類專屬姿勢與構圖自動補上
4. 這讓大量歷史卡片即使未逐張補齊，也能先吃到更穩定的姿勢與構圖語言。

## 階段結論

「專屬姿勢庫」已從規劃階段進入正式實作階段，且不是只做少數分類，而是先把四個高價值大類整體落到核心邏輯。

下一步仍建議：

1. 分批把資料本體的 `prop` / `comp` 補齊
2. 後續再逐步擴到科幻 / 動漫 / COS / 水下等類別的專屬姿勢庫

## 補充說明

本輪也嘗試建立第三層資料本體批次補欄位腳本，但驗證後確認目前腳本對單行條目格式不夠安全，會破壞 `index.html` 物件結構，因此已停止採用該批次寫回路線，並恢復主檔至備份版本。

後續第三層資料本體補齊，需改採更穩的區塊化處理或格式先標準化後再批次寫回。
