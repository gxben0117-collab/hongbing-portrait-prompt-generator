# V1.23

日期：2026-05-22

## 本次更新

1. 將 prompt engine 進一步改造成 `identity-first architecture`，把 `face_lock_core`、`pose_coherence_core`、`proportion_core`、`makeup_safety_core` 固定放在輸出前段。
2. 新增 `REFERENCE PRIORITY OVERRIDE`，明確規定任何風格、角色、電影感、美術描述若與身份衝突，必須由身份保留強制覆蓋。
3. 將 `仰拍`、`回眸`、`電影預告 / movie trailer` 列為硬限制路線：
   - 移出可選角度 / 鏡頭語言主路徑
   - 預設值不再導向這些模式
   - 輸出前會做 safer replacement
4. 新增 `scripts/verify_identity_engine.mjs`，可直接驗證白淺與素錦測試 prompt 是否包含核心模組，並檢查 `movie trailer` / `low angle` 是否已被清除。
5. 補齊 `docs/architecture/Identity-First Prompt 架構規格.md` 與 `核心資料/正式preset/`，把工程規格與角色範本正式拆開管理。

## 階段結論

這一輪不再只是「加幾句鎖臉描述」，而是把防換臉、防臉身不協調、防頭過大感的核心排序正式寫進產生器主流程，讓角色、場景、服裝只能接在身份核心之後。
