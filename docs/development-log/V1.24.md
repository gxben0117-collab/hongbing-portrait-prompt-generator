# V1.24

日期：2026-05-22

## 本次更新

1. 完成 `TASK-001` 的 prompt engine 第二階段改造，新增 `faceDesc` 前端欄位與 `buildFaceAnchor()`，把可選的臉部文字錨點固定插入 prompt 第 2 段。
2. 將 `Avoid: ${AVOID_LOCK}` 從 prompt 尾段前移到第 3 段，避免防換臉與防姿勢失衡規則因尾段注意力衰減而失效。
3. 將所有 `TPLS.char` 中性化為純世界觀描述，只保留場景與角色所處世界，不再使用 `heroine`、`beauty`、`divine presence` 等 archetype 詞。
4. 將 `ANCIENT_BOOST` 縮短成安全古裝強化版，只保留 2 到 3 件頭飾、限制頭部輪廓膨脹，並要求古風環境與服裝層次一致。
5. 更新 `sanitizePromptText()` 與驗證腳本，將 `movie trailer`、`fashion editorial camera language`、`perfect beauty`、`cat-eye`、`jumping`、`back-facing` 等高風險詞一律轉為 safer replacement。

## 階段結論

這一版把身份保護從「核心段落順序」進一步推到「文字錨點 + 反模式前移 + 模板中性化」三層同步落地。換句話說，現在不只是 prompt 前面多幾句鎖臉，而是前端輸入、模板資料、builder 組裝與反模式清洗都在同一個 identity-first 邏輯下工作。
