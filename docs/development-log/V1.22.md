# V1.22

日期：2026-05-22

## 本次更新

1. 針對 `index.html` 內 `CATS` 風格範例資料，正式補齊缺漏的 `prop` / `comp` 欄位，讓高風險分類不再只剩 scene 而缺少姿勢與構圖描述。
2. 新增 `scripts/fill_style_pose_fields.mjs`，改用結構化解析與安全寫回方式處理大型資料，不再依賴脆弱的正則插入。
3. 升級 `scripts/report_data_gaps.py`，改為解析實際資料物件驗證缺口，避免因 JSON / JS 表示格式變化而誤判。
4. 將主頁版本推進至 `v0.39`，保留 `versions/index_v0.39.html` 備份。

## 階段結論

這一輪已經把第三層的「資料本體補齊」真正落地，現在不只是 runtime fallback 會引導姿勢，而是風格範例卡片本身也具備可直接被 ChatGPT 讀取的動作與構圖語意。
