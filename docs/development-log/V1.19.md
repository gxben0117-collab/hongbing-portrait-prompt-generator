# V1.19

日期：2026-05-22

## 本次更新

1. 將 `core.js` 中的分類專屬姿勢庫由「表面姿勢描述」提升為「角色行為與場景敘事導向」。
2. 調整四大高價值類別的姿勢提示方式：
   - 旅拍：由單純走動/回眸改為像真實旅人與地點互動
   - 婚紗：由抬手托紗改為進場、等待、整理禮服、婚禮情境中的自然行為
   - 漢服 / 朝代：由拿扇持物改為依角色身份、社會場景、情緒脈絡決定行動
   - 女王 / 魔王：由強勢姿勢改為治理、下令、審判、登階、臨朝等權力行為
3. 在通用姿勢引導中加入明確規則：
   - 不要只做隨機手勢變化
   - 要先判斷角色身份、情境、氛圍與當下故事，再決定動作

## 階段結論

目前姿勢生成方向已從「讓圖不要站著發呆」提升為「讓角色在場景裡有合理行為」。
