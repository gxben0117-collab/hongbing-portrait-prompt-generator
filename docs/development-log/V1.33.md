# V1.33

日期：2026-05-23

## 本次更新

1. 新增 `prompt_governance.js`，集中管理黑單字眼、文字替換、50 / 70 / 80 / 85mm 焦段策略、姿勢模式與分類焦段規則。
2. 將「三分側面」調整為「鎖臉微側」，由原本偏 45 度側臉改為 10-15 度微轉，避免鎖臉時五官角度變怪。
3. 擴充焦段選項：
   - `50mm 全身最穩`：古裝全身、大衣裙、寬袖與完整服裝優先
   - `70mm 平衡人像`：兼顧臉部好看與頭身比例
   - `80mm 角色近景`：COS / 遊戲 / 角色感近景
   - `85mm 半身美臉`：婚紗半身、近景與雜誌美臉
4. 調整 `TPL_DEFAULTS`，依風格自動帶入最佳焦段：古裝與旅拍多數保留 50mm，女王 / 現代 /暗黑美型走 70mm，COS / 遊戲 / 賽博走 80mm，婚紗走 85mm。
5. 進階動作指定移除高風險「回眸一望 / 動態揚臂」選項，改為鎖臉正面、鎖臉微側、三分之四身、全身穩定、安全坐姿、緩步動作、安全持物、婚紗柔和、女王威儀。
6. 新增 `scripts/lint_prompt_governance.mjs`，檢查 governance 設定、焦段選項、黑單、分類規則與 HTML 載入順序。
7. 新增 `scripts/report_risk_flags.mjs`，先以報告形式產出每張卡的 `risk_flags` 與 `approved / review` 狀態，作為未來寫入正式 metadata 的前置步驟。
8. 更新 `scripts/verify_identity_engine.mjs`，讓身份引擎驗證涵蓋新焦段與 governance 載入。
9. 更新 `scripts/build_dist.py`，建置時同步 `prompt_governance.js` 到 `dist/`。

## 階段結論

本輪把 prompt 改良從散落在 `core.js` 的硬編碼，推進到可維護的治理層。之後若要新增黑單字、焦段規則、姿勢模式或分類特例，優先修改 `prompt_governance.js`，再由 lint 與 identity engine 驗證。
