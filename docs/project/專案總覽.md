# 專案總覽

## 專案名稱

紅兵風格寫真咒語產生器

## 專案定位

這是一個以單頁 HTML 為核心的風格寫真咒語產生器，整合：

- 古裝神話角色寫真
- 景點旅拍與外景大片
- 婚紗與高級寫真
- COS / 奇幻 / 暗黑角色風格
